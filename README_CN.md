## 🌟 v0.7.0 最新动态
最新的 v0.7.0 版本标志着 Bot 从简单的聊天助手进化为 **复杂工作流自动化引擎**：
- 🧩 **可插拔工作流引擎**：模块化架构，支持轻松扩展功能模块 [1]。
- 🚀 **FlowTask V2**：可靠的任务流执行，支持 **结构化计划生成** 与自动任务拆分 [1, 2]。
- 🗺️ **任务路由 (Task Router)**：智能分析用户意图，精准分发任务到对应工具 [1]。
- 🏗️ **多 Agent 架构**：支持多账号同时登录，每个账号拥有独立环境、记忆和目录 [1, 3]。

## 🚀 核心特性

### 👤 多 Agent 系统
支持多个微信账号独立运行，每个 Agent 互不干扰：
- **独立工作目录**：Kimi 可直接读写本地文件 [4]。
- **长期记忆**：跨会话的持久化上下文 [2, 4]。
- **能力模板**：可设定为程序员、写作助手、Vlog 创作者等不同角色 [2]。

### ⏳ 耗时任务 (LongTask) 与 流程任务 (FlowTask V2)
在地铁上也能处理复杂工作，不阻塞正常聊天：
- **实时进度推送**：每 30 秒自动报告进度 [5]。
- **百分比精度**：基于实际工具调用次数计算进度 [5]。
- **高可靠性**：支持最多 4 个任务并发，且**崩溃后可自动恢复** [5]。

### 📅 智能定时任务
支持自然语言或 Crontab 表达式：
- `/task create "每天早上9点搜集AI资讯"` [2]。
- AI 自动解析意图，确认后即可生效 [4]。
